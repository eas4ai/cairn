# 0002: ara2-style numbered domain specs

Date: 2026-08-10

Scaffolded spec sets use the pattern proven in ara2-bridge
(docs/specs/<project>/): numbered domain specs behind a 00-overview
keystone with a spec map; shared skeleton Scope -> content -> Acceptance
criteria -> Decisions and revisions; decisions distributed into the specs
they affect. Rejected: one file per feature (discovery problem, no home
for cross-cutting behavior) and a single spec document (context blowout;
not ingestible for large projects).
