# Iteration 003 -- The CONF revision: section-level Agreed and the falsifier rules

Status: Scope contract
Agreed: 2026-09-02

The language check and evidence map spec is
docs/superpowers/specs/2026-09-01-same-page-conformance.md (CONF).
Iterations 001 and 002 are closed. "Shipped" for a CONF rule means:
implemented in skills/new-project/scripts/language-check.mjs, with a
test in tests/language-check.test.mjs that produces the rule's
falsifier state and shows the check reporting it, and the evidence map
row raised to Covered with that test cited.

## In

- CONF-015 -> the check treats a requirement under a section carrying
  an `Agreed:` line, before its first requirement, as Agreed whatever
  the file's Status line says; a section marker applies to the section
  and its subsections until a heading of the same or higher level,
  which is the engine's reading (specs.ts), so the two never disagree
  about which identifiers are Agreed.
- CONF-016 -> an Agreed `MUST` or `MUST NOT` requirement with no
  `Falsifier:` line directly under it is a finding (LANG-070,
  LANG-075).
- CONF-017 -> a `Falsifier:` line under a requirement whose only
  keyword is `MAY` is a finding (LANG-073).
- CONF-018 -> a `Falsifier:` line that contains a normative keyword is
  a finding (LANG-077).
- CONF-040 as it stands -> with CONF-015 in force, every identifier
  under an Agreed section of the engine spec is required in
  conformance.md by the check, not only by this contract; the 146
  rows already exist.
- The CONF spec's new pass-one rules sit in a section that carries its
  own `Agreed:` line inside a file whose Status stays Draft for
  review, so the revision exercises the rule it adds.
- docs/MANUAL.md chapter 7 cites the four rules; the CONF spec's
  Decisions and revisions carries the revision; recon.md Gaps 1 and 6
  close; skills/existing-project/SKILL.md Stage 2 says the check
  enforces the section convention.

## Out

- Every engine layer (L3 through L6) and every ENG requirement.
- Any change to the LANG spec, the templates, or the drift gate.
- Confirming the LANG and CONF specs Agreed as files (recon.md Gap 2).

## Definition of done

- Map rows for CONF-015 through CONF-018 cite the tests that produce
  their falsifier states.
- `bun test` passes; the language check reports zero findings for

- A fixture with a Draft file holding an Agreed section, an Agreed
  `MUST` without a Falsifier line, a `MAY` with one, and a Falsifier
